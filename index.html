Configure a browser test

A compact run form for testing a product journey across existing AdsPower profiles. This web page generates configuration files only and can be deployed to Vercel. The actual runner must execute locally on your Mac where AdsPower is installed, as it requires access to the AdsPower Local API at http://local.adspower.com:50325.

Target

Use one query per run. If Product URL is supplied, the runner visits it directly.

Existing AdsPower profiles

Add or replace IDs with existing profiles only. The runner uses existing profiles and never creates or deletes them. Profile IDs can be found in your AdsPower application.

Interaction plan

Safety defaults: no checkout, payment, account changes, or CAPTCHA solving. The runner stops immediately on security challenges and always cleans up profiles in the finally block.
